# Security

This repository is a teaching example. It contains only made-up tenants, SKUs and locations.
It is not the code that runs any production system.

If you find a way for a token for one tenant to read or change another tenant's data
in this example, please do not open a public issue. Email inquiry@rorixtech.com instead.

Never commit real tokens, keys, tenant identifiers, hostnames or customer data here.
CI runs secret scanning on every push and pull request.
